## What is Doc?

Doc is a documentation site built with [zudo-doc](https://github.com/zudolab/zudo-doc), a minimal documentation framework powered by zfb and MDX. Component evidence pages are generated by [zudo-circuit-doc](https://github.com/Takazudo/zudo-circuit-doc).

## Key Features

- MDX authoring with rich component support
- Fast static site generation via zfb
- zfb's zudo-wind styling layer with zudo-doc's Classic theme
- Optional i18n, search, and more
